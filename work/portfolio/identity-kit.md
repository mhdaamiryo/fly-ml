# Identity Kit — Muhammed Aamir

**Purpose:** A compact, repeatable visual system for my personal developer portfolio and project case studies.

## 1. Typography

**One font: Inter** — free, available through Google Fonts.

- **Headings and name:** Inter SemiBold / Bold (600–700)
- **Body and interface:** Inter Regular / Medium (400–500)
- Use the same family throughout for a consistent, uncluttered appearance.

## 2. Colour palette

A restrained four-colour palette. The blue is the main brand colour; the pale blue is the only supporting accent.

| Role | Colour | Hex |
|---|---|---|
| Main colour | Muted blue | `#315C8C` |
| Near-black text | Charcoal | `#171A1F` |
| Near-white background | Off-white | `#F7F8FA` |
| One accent | Pale blue | `#DCE8F5` |

**Usage:** Use off-white for the main canvas, charcoal for readable text, muted blue for links and primary actions, and pale blue sparingly for subtle highlights or selected states. Avoid adding extra colours for decoration.

## 3. Logo and favicon

The identity uses a simple geometric **A monogram** in a rounded muted-blue square. The wordmark pairs it with the name “Muhammed Aamir” in Inter. It is intentionally simple so it remains legible at small sizes and does not compete with project screenshots.

## 4. Two-line style note

> Use Inter throughout, with muted blue `#315C8C`, charcoal `#171A1F`, off-white `#F7F8FA`, and pale-blue accent `#DCE8F5`.  
> Keep the mood minimal, calm and technical: clear typography and generous space should frame the projects, while the work itself remains the loudest thing on the page.

**Add the two-line style note above to the Claude Project instructions** so future page and case-study generation follows the same identity.

## 5. Consistency rules

- Do not introduce additional fonts or colours without a clear reason.
- Use the same logo, colour roles and typography across the portfolio and case studies.
- Keep project screenshots authentic; never recolour or fabricate them to fit the palette.
- Prefer simple layouts and subtle interactions over decorative effects.
- Check readability and contrast, especially for small text and buttons.
